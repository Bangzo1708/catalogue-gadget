The Catalogue Photo of an Impossible Gadget. Your entry is a program that writes one image to /output/entry.png: a catalogue photograph of an impossible gadget — the BANANAFORM 3000, a benchtop banana straightener. A curved banana feeds in on the left, the machine's rollers press it flat, and a perfectly straight banana emerges on the right, with a single spare curved banana resting on the bench as the only accessory.

## Run it

```sh
python3 main.py
```
